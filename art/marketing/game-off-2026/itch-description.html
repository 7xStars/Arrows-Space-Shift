A damaged Warp Drive. Three Acts. Change the space around each threat.

Arrow Space Shift is a manual-fire shoot-'em-up. Fold distance to bring a target closer. Your shots move faster there. Incoming shots move faster too. Unfold to gain more reaction time.

Three ways to read space

  • Act I: Steer through scrolling formations, quiet asteroid belts, and the Klein Fleet.
  • Act II: Read attacks that return through Klein boundary crossings.
  • Act III: Capture hostile fire, store finite echoes, and choose when to release them.

Choose a ship and equipment. Read the warning. Keep track of the same threat when its path changes. Filled shots are live threats. Hollow images show possible future positions.

Defeat each boss. Collect its drive part physically. Reach extraction to bank it. This edition ends after the Curvature Gate in Act III. Reached sections remain available for replay.

Controls

  • Left / Right: Steer.
  • Space: Hold to fire.
  • Left Shift: Fold space.
  • Right Shift: Unfold the latest field.
  • C / E: Capture / release after the Projective Module unlocks.
  • P / Escape: Pause or resume.

A keyboard is required. Select the game view before using the controls. Use fullscreen for a larger view.

Sound and saves

Original electronic music and action sounds accompany the campaign. The speaker in the lower-left corner turns sound on or off. Options has separate music, effects, and ambience levels. If the browser blocks automatic sound, select the speaker once.

Section checkpoints and settings save in the same browser when site storage is available. Options includes progress export and import. Use export before changing browser or site address.

Reduced motion and decorative-effect settings are available. Essential warnings remain visible when sound is off.
