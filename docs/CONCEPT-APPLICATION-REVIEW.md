## Five-star application scale

These stars describe implementation coverage in the declared campaign.
They do not measure enjoyment, musical quality, comprehension, or expected jam votes.
They are not a conversion of the GD-001 zero-to-four rubric.

| Stars | Meaning |
|---|---|
| 1/5 | The concept is defined, but no executed expression was found in the reviewed project scope. |
| 2/5 | An executed laboratory or separate study exists. The campaign connection is absent or limited to a small gesture. |
| 3/5 | Actual campaign rules or feedback express the concept, but important connections or representative cases remain incomplete. |
| 4/5 | The concept affects several campaign situations and has relevant runtime or regression evidence. Specific release cases remain open. |
| 5/5 | The declared campaign expression has consistent demanding-case, interruption, and continuation evidence. No material scoped application gap remains. |
| U | Evidence is insufficient to assign an application rating. Unknown is not zero. |

No aggregate score is calculated.
The GD-001 Orthogonal and Cognitive profiles remain separate.
Human noticing, prediction, understanding, and transfer require suitable player evidence.
None of those human outcomes receives a star rating here.

## Highest-impact campaign work

1. Connect the produced title and selected Act recordings to actual campaign playback.
2. Retain the same attack motif when the same physical object crosses a real boundary.
3. Keep forecasts silent as physical events. Keep their hollow visual form and static destination information.
4. Add a small primary/secondary motion response to an actual recoil or impact event without changing its collider.
5. Preserve safe recovery intervals and the quiet musical state during those intervals.
6. Use ordinary keyboard input to complete a fresh campaign and record every earned reward receipt.
7. Obtain human predictions on unfamiliar crossings after the runtime changes pass.

The first five tasks can improve campaign expression without adding another game mode or rewriting its engine.
The last two tasks answer questions that source inspection cannot answer.
