# Current player review

Candidate: `0.25.0-dev.1`.
Status: procedure only. Results are not supplied by this file.

Use the packaged build. Record the build hash and browser.
Record the ship, layout seed, input device, and sound settings.
Keep the first session free of coaching.
If a player needs help, record the help before continuing.

## First five minutes

1. Start a clean profile at Level 0.
2. Observe movement, manual fire, fold, and unfold.
3. Ask the player what the fold changed.
4. Ask the player what happened to incoming fire inside the fold.
5. Record the first unexpected hit and the player's explanation.
6. Ask which action the player would try next.

Do not infer understanding from a completed instruction.
Record the player's words before explaining the rule.

## Returns and attack control

Use a declared reached-stage profile for these short tests.
Keep that profile separate from the fresh campaign.

1. Ask which visible objects can cause damage now.
2. Ask which images forecast a future position.
3. Ask where one marked projectile will return.
4. Observe a real boundary crossing.
5. Ask whether the returning projectile is the same object.
6. Test the same relationship with an unfamiliar formation.
7. Observe one deliberate capture and release.
8. Repeat the critical visual questions with sound off.

Record correct answers, missed warnings, and false collision expectations.
Measure response time only when the recording supports it.
The proposed critical recognition target is 85%.
Do not report that target as achieved without measured participant results.

## Music and mix

1. Play the revised music-only Act I and Act IV clips.
2. Ask whether each clip has a recognizable musical phrase.
3. Play the corresponding action mixes.
4. Ask which action sounds become difficult to hear.
5. Play one ordinary combat scene for five minutes.
6. Record fatigue, repeated sounds, and unwanted interruptions.
7. Check pause, resume, mute, and the independent volume controls.

Record speakers or headphones and the selected volume levels.
Keep musical preference separate from missing or obscured warnings.
The first user review found the initial stress clips sounded like SFX.
The revised score requires another listening review.

## Completion and final review

Complete one fresh campaign through extraction, repair, and ending.
Check reload after an exposed core and after a collected core.
Neither case must bank the final part.
Check reload after successful extraction and after the ending.
Record any assistance, retry, exception, or missing asset.

After play, request separate 1-to-5 ratings for Overall, Gameplay, Graphics,
Audio, Innovation, and Theme Interpretation.
Ask for one concrete reason for each rating.
Do not convert unit tests, feature counts, or this checklist into player votes.
The development target is 4.5/5 in every category.
The target is not a reported result.
