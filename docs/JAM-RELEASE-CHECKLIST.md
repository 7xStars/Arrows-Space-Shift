## Concrete publication sequence

1. Complete the candidate's human play and listening review.
2. Resolve the history record and eligibility concern.
3. Review `NOTICE.txt` and the AI disclosure with the user.
4. Preserve the existing source-license status. Do not choose a new license without the user's instruction.
5. Verify the selected PLAY and SOURCE archive hashes.
6. Prepare the public repository from current source. Keep private reference PDFs and caches excluded.
7. Review the exact repository changes before publication.
8. Upload PLAY as an HTML game with `index.html` at the archive root.
9. Test the actual hosted game, fullscreen mode, saves, and audio unlocking.
10. Publish the selected public source before the deadline.
11. Submit the itch.io game through the Game Off jam page.
12. Verify that the jam submission lists the intended game and public repository.

The [jam page](https://itch.io/jam/game-off-2026) requires both public source and an itch.io submission.
The deadline is December 1, 2026, at 13:37 PST.
Record the verified public repository commit separately.
A source push does not publish the game on itch.io or submit it to the jam.
