# Structural disclosure and Analysis Framework release gates

This is an implementation and evidence plan, not a completed evaluation of human experience. The project's Orthogonal+Cognitive rubric uses 20 criteria, two per axis per lens, with 0–4 ratings and U for unreviewed. Unknown is not zero. No 4/5 ratings are asserted here without suitable human evidence.

## Seven-step Structural Disclosure Method applied to folds/joins

1. **Decompose:** positions, headings, operation type, seam rule, fold depth, time-to-contact, player available motion.
2. **Change representation:** visible entrance/destination markers, conventional versus folded pattern, neutral music variant versus transformed motif.
3. **Discriminating probes:** same shot under no fold / fold / projective intrusion, or with/without an intentional seam crossing.
4. **Candidate relationship:** if the player understands the changed path or arrival, they can use it to survive or attack deliberately.
5. **Establish:** geometry-cue tests and movement/collision tests; run real gameplay simulations for demanding cases separately.
6. **Disclose:** short in-context cues, a physical repair reward, an optional Guide, and no mandatory mathematical lecture.
7. **Transfer:** ask an unfamiliar-pattern question in the playtest form, measure independent application, and revise based on the responses.

## Critical conditions (project rubric G1–G5)

- **G1 Essential actions:** Basic controls and the C/E systems are covered by existing tests, but human-supported input reliability remains U.
- **G2 Consequential information:** Current-course geometry forecasts now appear before predicted joins; comprehensive timing in dense hybrid fights remains U.
- **G3 Truthful action status:** The relay is visibly distinguished as exposed, aboard, and banked, matching pickup and extraction events; player comprehension remains U.
- **G4 Promised response opportunity:** U. A survival simulation or blind playtest must establish reachable response under actual timing and ship speed. Do not claim Pass.
- **G5 Persistent consequences:** Existing tests check module and fleet persistence; stress-testing interrupted storage transactions remains U.

Human goals proposed for the first 12–20 external testers, not observed results: 90% initial controls, 80% fold explanation, 80% damage explanation, 75% learning transfer, 80% wanting to continue, median Overall 5 in a late test round. These are aspirational gates and cannot guarantee jam ratings.
