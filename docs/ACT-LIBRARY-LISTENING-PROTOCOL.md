# Act library listening protocol

Protocol: `STC-LISTEN-r1`.
Candidate: `stc-act-library-r1`.
Page: `music-library.html`.
Owner: Design and Playtest Research, under the user's creative direction.
Status: Prepared. No human session has been conducted under this protocol.

## Decisions and questions

Use the study to decide which pieces and vocabulary need revision.
Keep a musical preference separate from a recognition result.

1. Can listeners retain a bass phrase when atmosphere enters?
2. Can listeners distinguish a change of note order from a change of timbre or register?
3. Can listeners recognize a voicing change without assuming a new harmonic identity?
4. Does atmosphere obscure the kick, bass, or an existing game warning?
5. Are the stereo motion and high-frequency textures comfortable?

The first four questions concern distinctions.
The fifth concerns comfort and preference.
No measured recognition target or enjoyment score has been achieved.

## Session preparation

Record the exact source or archive revision.
Record the browser, operating system, audio device, and output route.
Record whether the listener uses headphones, speakers, or mono output.
Record musical experience and prior exposure to these studies.
Ask the listener to select a comfortable volume.
Keep that level fixed during a comparison.
Allow the listener to stop or lower the level at any time.
Obtain agreement before retaining a recording or identifiable notes.

Keep Inspect the experiment closed before the first response.
Do not show the intended invariant or operation labels before a recognition task.
If those labels were visible, record that assistance.
The current page has no blind comparison mode.
A moderator can operate the visible page while the listener faces away from the display.
Do not hide the page, because hidden-page handling pauses playback.

## First pass: musical character

Use one short piece from each Act.
Change the Act order between listeners.
Avoid describing a piece as successful, hypnotic, deep, or clear before the response.

Use these neutral prompts:

- "Which sounds do you follow most easily?"
- "What remains the same during the passage?"
- "What changes?"
- "Does any sound make another part difficult to hear?"
- "Where would you reduce or remove a layer?"
- "Was any passage uncomfortable?"

Store the exact statement before adding an interpretation.
A preference for more atmosphere does not establish better warning recognition.

## Matched core and atmosphere comparison

Use the two-minute pieces for the first comparison.
Use the same source interval in both conditions.
The interval from 30 to 50 seconds is a proposed starting case.
Confirm that the chosen interval contains atmospheric activity.
If it does not, choose another interval and record the reason.

1. Select the piece.
2. Pause playback.
3. Set Track position to the selected start time.
4. Turn Include atmosphere off.
5. Play the interval.
6. Pause at the selected end time.
7. Record the first response.
8. Set Track position to the same start time.
9. Turn Include atmosphere on.
10. Play the same interval.
11. Record the comparison response.

Reverse the condition order for the next listener.
Do not infer a causal improvement from one fixed-order comparison.

The atmosphere control removes sustained pads, noise, and their return.
Act III chord stabs remain in the core.
This is not an all-harmony-off comparison.
Adding the atmosphere can also change total loudness and masking.
Record those alternatives before attributing a difference to structural information.
A later level-matched comparison can investigate that confound.
Do not normalize the stems independently to create such a comparison.

Ask the listener to describe or reproduce the recurring bass rhythm.
Record whether that description changes between conditions.
Do not count a corrected response after feedback as an unassisted result.

## Operation order and harmonic persistence

Use a four-minute piece with both ordered operations.
First present its reference phrase.
Then present one transformed phrase without its label.
Ask what changed and what remained.
Record the response before showing the score.

After that response, show the source and both operation results.
Explain that the composer uses reverse and rotation by three positions.
Do not describe the musical operations as Bolza side-pairing operations.
Use a new asymmetric note/rest cell for the transfer question.
Ask the listener to predict the result before playback or feedback.
Record the first result, explanation, exposure, and assistance.
The current page does not automate this new-cell transfer task.
It remains a supervised follow-up, not an implemented game lesson.

For voicing, compare a source chord with an octave-displaced version.
Ask whether the listener hears continuity and why.
After the response, show the pitch classes.
Use a new voicing of the same chord for a further question.
Distinguish note-array equality from a listener's account of harmonic identity.
The latter depends on register, rhythm, timbre, context, and prior listening.

## Later gameplay test

This part is proposed. It is not implemented by the music library.
Select one existing, verified boundary transformation in the game.
Keep the encounter seed, visual warnings, controls, difficulty, and actual geometry fixed.
Use one audible condition and one music-muted condition.
Keep essential sound effects separate from music in the comparison.
Do not remove visible warnings to make an audio result appear useful.

Ask the player to predict the return position before feedback.
Use a new position or formation after the initial example.
Record the first choice, warning opportunity, damage, response time, and explanation.
Inspect whether the player used the geometric rule, a memorized location, or a musical cue.
Successful survival alone does not establish geometric understanding.
The current music has no new semantic mapping to game transformation events.
Do not report a synchronized-versus-mismatched result without that separate implementation and test.
