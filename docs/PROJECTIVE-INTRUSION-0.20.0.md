# Arrow Space Shift 0.20.0 — The Projective Intrusion

## Scope

Version 0.20.0 completes Act II without changing Act I. The first eight Act II stages retain the canonical scrolling-shmup grammar and culminate in a ninth-stage boss whose battlefield combines the learned Klein surface with projective identification. The physical reward is the Projective Module.

## Boss progression

1. **Klein baseline.** Fan, Gap, Sweep, Wall and Return use the established Act II surface.
2. **Projective intrusion.** The Antipodal Anchor alone uses a projective top/bottom identification while the side joins remain Klein. Projectile density drops and the field pauses for 2.2 seconds so the new rule can be observed.
3. **Stabilized hybrid.** The Projective Core and Klein Anchor begin emitting hybrid trajectories while the Antipodal Anchor remains explicitly projective.
4. **Hybrid mastery.** Klein, projective and hybrid trajectories coexist. The attack grammar is unchanged; the player identifies which boundary rule transports each threat.

Each health threshold clears current hostile bullets, cancels telegraphs, displays a geometry announcement, and creates a short recovery interval. This makes the geometry change the lesson rather than hiding it inside continuous pressure.

## Hybrid gameplay quotient

The encounter deliberately overlaps two rules:

- Left/right joins retain the Klein reflection and orientation change.
- Top/bottom traversal introduces an antipodal horizontal identification for projective and hybrid actors.

This is an authored Klein/projective module overlap. It is not presented as a pure rectangular model of the real projective plane.

## Readability

- Klein joins retain their asymmetric twist marks.
- Projective joins use opposed circles, a diagonal mark, and a distinct projectile shape in addition to color.
- Telegraph labels include `P` or `K+P` when the shot does not use the ordinary Klein rule.
- The HUD shows the current geometry phase.
- Phase changes use a separate audio cue.

## Reward and persistence

Destroying the boss is not sufficient. The player must:

1. Physically collect the Projective Module.
2. Cross the extraction line.
3. Survive any already-stored Impact Buffer debt.

The module is then stored additively beside the Klein Relay. It cannot remove the relay or relock the starter fleet.

## Preserved rules

- Act I chapter order and tuning remain unchanged.
- Manual forward fire remains the common weapon.
- The player remains between the bottom and halfway point in Act II routes.
- Folding changes travel timing for both sides and does not accelerate the game clock.
- Hostile bullets clear after final boss defeat.
- Fan, Sweep, Gap, Aimed, Wall, Return, Crossfire and Spiral remain the same canonical grammar.

- Act I chapter stability.

- Fold timing and projectile fold transitions.
- Pressure Field roles, grazing and collision-core defaults.
- Klein Warden phases.
- Klein versus projective boundary transport.
- All four hybrid-boss phases.
- Physical Projective Module collection and extraction.
- Additive persistence of both geometry modules.
