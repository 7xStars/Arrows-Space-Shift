# v0.23.8 — Klein Manifold Readability

Development candidate; not deployed to ChatGPT Sites.

- Solid, filled hostile bullets remain live simulation objects. Klein bullets receive a slanted-notch glyph.
- Render-only hollow image near a predicted Klein crossing now marks where the same projectile will appear; it is not an additional collidable bullet.
- The edge marker grows in emphasis as a crossing approaches; a limited set of forecasts avoids screen clutter.
- A small chart/frame indicator shows the player's transported physical-forward sign.
- The Flight Guide explains the same-shot vs image distinction, and Options can disable extra manifold previews.
- Existing combat, topology, drops, saves, stage numbering, music, and AI are unchanged.
- Mathematical correction: a Klein bottle has no globally distinct front/back collision layer; a chart image is not automatically harmless.

Test scope: pure preview rules, actual edge-image collision, rendering side effects, preference persistence, and old suite.
